# Pradip Jha — Art Director & Printmaker

Portfolio website for Pradip Jha: film and TV art direction, exhibitions and printmaking work.

**Live site:** https://yatharth-jha-yx.github.io/Pradip-WebSite/

## What's here

- `index.html` — the single-page site
- `support.js`, `art-bg.js` — the scripts the page runs on
- `assets/` — images for each section (films, exhibition, TV and more)
- `.nojekyll` — tells GitHub Pages to serve the files as they are

## Updating the site

Edit the files, then commit and push to `main`. GitHub Pages republishes within a minute or two.
